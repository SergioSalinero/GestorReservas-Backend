# Backend del Gestor de Reservas

## Instalación

 - Node 18
 - npm como gestor de paquetes

 1. Clonar repositorio:
 ```bash
    git clone git@github.com:Maniaticos1/GestorReservas-Backend.git
    cd GestorReservas-Backend
 ```

 2. Instalar dependencias:
 ```bash
    npm install
 ```

 3. Crear archivo `.env` a través de `.env.template` y rellenar las variables:
  ```bash
    cp .env.template .env
 ```

 4. Ejecutar:
  ```bash
    node src/server.js
 ```
